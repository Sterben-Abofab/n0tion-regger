## 🚀 Быстрый старт (За 1 минуту)

### Шаг 1: Запуск софта
Запустите файл **`start.bat`** двойным кликом мыши.
* Никаких сторонних программ устанавливать заранее **НЕ нужно** (Node.js не требуется — все инструменты кодинга работают нативно через Python).
* Если Python еще не установлен, скрипт автоматически скачает и настроит его.
* Автоматически откроется веб-панель в браузере по адресу: **`http://localhost:8000`**.
* Все серверы поднимутся в фоне:
  * **Порт 8000**: Веб-интерфейс регистрации и управления.
  * **Порт 8765**: Автономный кодинг-шлюз с вызовом локальных инструментов (файлы, PowerShell-терминал). Провайдер: `abofab`.
  * **Порт 8081**: Текстовый чат-прокси.

---

### Шаг 2: Регистрация аккаунта Notion
1. В открывшемся браузере на первой вкладке **«Регистратор Business Trial»** выберите способ почты:
   * **Catch-All (Рекомендуется)**: если у вас настроен свой домен для пересылки писем.
   * **Mail.tm (Временная почта)**: если нужно быстро зарегистрировать чистый тестовый аккаунт в 1 клик.
2. Нажмите кнопку **«Запустить регистрацию & активацию Trial»**.
3. Браузер автоматически пройдет регистрацию и активирует 30-дневный Business-триал.
4. Свежесозданный аккаунт **автоматически станет активным для API** — перезапускать программу не требуется!

## 💻 Использование в OpenCode CLI (Автономный кодинг)

Для работы с кодом и проектами используется эндпоинт **`http://127.0.0.1:8765/v1`**, который дает моделям прямой доступ к чтению/редактированию файлов вашего ПК и выполнению команд в терминале.

### 1. Добавление провайдера в OpenCode
Откройте файл конфигурации OpenCode (нажмите `Win + R` и вставьте):
`%USERPROFILE%\.config\opencode\opencode.jsonc`

Добавьте в раздел `"provider"`:
```jsonc
"abofab": {
  "name": "abofab",
  "npm": "@ai-sdk/openai-compatible",
  "options": {
    "baseURL": "http://127.0.0.1:8765/v1",
    "apiKey": "local-notion-bridge"
  },
  "models": {
    "opus-5": { "name": "Claude Opus 5 (Notion AI)" },
    "sonnet-5": { "name": "Claude Sonnet 5 (Notion AI)" },
    "sonnet-4.6": { "name": "Claude Sonnet 4.6 (Notion AI)" },
    "gpt-5.6-sol": { "name": "GPT-5.6 Sol (Notion AI)" },
    "gpt-5.5": { "name": "GPT 5.5 (Notion AI)" },
    "deepseek-v4-pro": { "name": "DeepSeek V4 Pro (Notion AI)" },
    "gemini-3.1-pro": { "name": "Gemini 3.1 Pro (Notion AI)" },
    "grok-4.6": { "name": "Grok 4.6 (Notion AI)" }
  }
}
```
*(Этот же блок можно в 1 клик скопировать из вкладки «API Шлюз» в веб-интерфейсе)*.

### 2. Запуск OpenCode с нужной моделью
Откройте терминал в папке вашего проекта и запустите:
```powershell
opencode -m abofab/opus-5
```
или для Sonnet 5:
```powershell
opencode -m abofab/sonnet-5
```

## 💬 Использование в обычных клиентах (Cherry Studio / Python / Cursor)

Если вам нужен обычный текстовый чат или вызов через Python:

### Параметры подключения:
* **Base URL**: `http://127.0.0.1:8081/v1` (или `http://127.0.0.1:8765/v1`)
* **API Key**: `sk-a99be21ebd90d87d796c314e8616b628` (для порта 8081) или `local-notion-bridge` (для порта 8765)
* **Имена моделей**: `opus-5`, `sonnet-5`, `sonnet-4.6`, `gpt-5.6-sol`, `gpt-5.5`, `deepseek-v4-pro`, `gemini-3.1-pro`

### Пример на Python (библиотека `openai`):
```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8765/v1",
    api_key="local-notion-bridge"
)

response = client.chat.completions.create(
    model="opus-5",
    messages=[{"role": "user", "content": "Привет! Как дела?"}]
)

print(response.choices[0].message.content)
```
