## 🚀 Возможности

- ⚡ **Автоматическая регистрация в 1 клик**:
  - Генерация чистых временных ящиков через **Mail.tm REST API**.
  - Возможность использовать свой личный/корпоративный email.
  - Автоматический перехват 6-значных проверочных кодов.
  - Прохождение онбординга: выбор роли **Work**, пропуск опросников, выбор **Free плана**.
  - Переход в **Teamspaces** -> создание рабочего пространства **Open** -> клик **"Start free trial"** (активация Notion Business на 30 дней без банковской карты).
  - Автоматический захват сессионных cookie (`token_v2`, `space_id`, `user_id`) и сохранение в пул `accounts/*.json`.
- 💎 **Красивая веб-оболочка (Dashboard)**:
  - Тёмная неоновая тема (Glassmorphism, Tailwind CSS, Lucide icons).
  - Пошаговый визуальный статус-бар пайплайна (8 этапов).
  - Живой стрим терминальных логов в реальном времени через **Server-Sent Events (SSE)**.
  - Список всех аккаунтов в пуле со счётчиком дней до окончания 30-дневного триала.
  - Экспорт аккаунтов в JSON и TXT в один клик.
  - Кнопка прямого перехода в Notion Web через реверс-прокси `/ai`.
- 🧠 **Полный функционал `notion_manager` (Go Core v1.0.2)**:
  - Готовый бинарник `notion-manager.exe`, встроенный в систему.
  - **Claude Code Compatibility**: трёхслойный мост для обхода системного промпта Notion, потоковый reasoning/thinking и tool calling.
  - **OpenAI Compatible API** (`/v1/chat/completions`, `/v1/models`): подходит для Cherry Studio, Continue (VS Code), Roo Code, Cline, NextChat.
  - **Notion Web Reverse Proxy** на `/ai`: работа в оригинальном веб-интерфейсе Notion AI под любым аккаунтом из пула.
  - Умная балансировка запросов по оставшейся квоте.

## 🎯 Как работает активация Business Trial

Программа строго выполняет официальный алгоритм получения бесплатного месяца Notion Business:

1. **Регистрация**: Ввод email на странице `app.notion.com/signup`.
2. **Верификация**: Получение и ввод 6-значного OTP-кода из почты.
3. **Онбординг**: Выбор варианта **Work** (для команды/бизнеса). Ввод названия компании.
4. **Пропуск шагов**: Пропуск приглашения участников и опросов.
5. **Выбор плана**: **КРИТИЧЕСКИЙ ШАГ** — выбор **FREE ПЛАНА**!
6. **Настройки**: Открытие `Settings & members` -> вкладка `Teamspaces`.
7. **Создание Teamspace**: Нажатие `+ New teamspace`, выбор доступа **Open**.
8. **Активация Trial**: В нижней промо-карточке нажимается **"Start free trial"** для тарифа Business.
9. **Готово**: Воркспейс получает статус **Notion Business на 30 дней**, открывая доступ ко всем бизнес-фичам и Notion AI!

## 🔬 Анализ запрошенных репозиториев

### 1. `SleepingBag945/notion_manager`
* **Роль**: **ЯДРО СИСТЕМЫ (Включено и полностью интегрировано)**.
* **Почему**: Высокопроизводительный сервис на Go. Он обеспечивает пул аккаунтов, отслеживание квот, реверс-прокси к Notion Web (`/ai`), API для Claude Code и OpenAI. Все новые аккаунты после регистрации мгновенно попадают в этот пул на горячую (hot-reload).

### 2. `PandaNePanda/notioncode_mcp`
* **Вердикт**: ❌ **НЕ НУЖЕН (Избыточен и неудобен)**.
* **Причина**:
  - Данный проект создан исключительно как мост между Notion AI и расширением **VS Code Codex** (`openai.chatgpt`).
  - Он требует сложной системной установки: фоновых демонов `systemd`/PowerShell, отдельного venv, npm-пакетов и **бинарного патчинга файлов расширения VS Code**.
  - Он поддерживает всего 3 модели (`opus-5`, `gpt-5.6-sol`, `fable-5`), маскируя их под имя `gpt-5.5`.
  - `notion_manager` решает эту задачу намного чище и универсальнее: он предоставляет стандартный OpenAI/Anthropic API, к которому подключается **любой** редактор кода (Continue, Roo Code, Cline, Cursor, Claude Code) без необходимости взламывать и модифицировать файлы VS Code.

### 3. `maverickxone/notion2api`
* **Вердикт**: ⚠️ **ОТДЕЛЬНЫЙ СЕРВЕР НЕ НУЖЕН, НО ПОЛЕЗНЫЕ МЕХАНИКИ ИНТЕГРИРОВАНЫ**.
* **Причина**:
  - Это Python/FastAPI сервер, который дублирует функционал прокси `notion_manager` (при этом Go-версия от `notion_manager` работает быстрее, поддерживает потоковый reasoning для Claude Code и веб-прокси `/ai`).
  - **Что мы взяли отсюда**:
    1. Идею браузерного перехвата сессии (DevTools Protocol / Playwright), которая используется в нашем авто-регистраторе.
    2. Полную базу сопоставления внутренних кодовых имён 23 моделей Notion AI (Claude Opus 5, Claude Sonnet 4.6/5, GPT-6 Astra, GPT-5.6 Sol, Gemini 3.1 Pro и др.).

## 💻 Быстрый запуск

### Запуск в 1 клик на Windows:
Просто запустите файл:
```bat
start.bat
```
Скрипт автоматически:
1. Запустит фоновое ядро `notion-manager.exe` на порту `8081`.
2. Запустит красивую веб-панель управления на порту `8000`.
3. Откроет браузер по адресу: `http://localhost:8000`.

## 🛠 Интеграция с Claude Code и сторонними клиентами

### 1. Claude Code CLI
```powershell
$env:ANTHROPIC_BASE_URL="http://localhost:8081"
$env:ANTHROPIC_API_KEY="sk-notion-ai"
claude
```

### 2. Cherry Studio / Continue (VS Code) / Cursor
- **Провайдер**: OpenAI Compatible
- **Base URL**: `http://localhost:8081/v1`
- **API Key**: любой ключ (или ключ из `config.yaml`)
- **Модели**: `claude-sonnet`, `opus-5`, `gpt-5.6-sol`, `orlando-quinn` (GPT-6 Astra), `gemini-3.1pro`

### 3. Оригинальный интерфейс Notion AI в браузере
Перейдите по адресу:
`http://localhost:8081/ai`
Вы попадёте в веб-версию Notion AI с сессией из вашего пула без необходимости вводить логин и пароль.
